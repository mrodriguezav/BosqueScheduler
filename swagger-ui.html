BosqueScheduler REST API v3.0.0-M3 OAS 3.0

Motor combinatorio en Java 21 / Spring Boot 3.3 para programación, validación (Patrón GoF Strategy: RD1–RD8, RB1) y exportación de horarios académicos.
Server Base URL: http://127.0.0.1:8080
Ir a Consola de Administración (/index.html) Ver Especificación OpenAPI JSON (/v3/api-docs)
GET /api/horario Retorna el estado íntegro del horario: bloques, cursos, docentes, aulas, sesiones ubicadas, sinUbicar (RF5) y auditoría. 
Presione Execute para consultar el estado actual...
POST /api/horario/cargar Carga el catálogo de entrada (datos_prueba_20cursos.json: 20 cursos, 12 docentes, 12 aulas) y ejecuta generarConRetroceso (RF1). 
Presione Execute para cargar y generar el horario...
POST /api/horario/mover Evalúa y aplica un traslado de bloque (RF2) o reasignación de aula (RF3) validando las 9 reglas Strategy en O(1). 
Presione Execute para validar movimiento...
POST /api/horario/reiniciar Actualiza parámetros de planeación (RF6: cupoMaximo, severidadRb1, inicioSemana) y regenera el horario completo. 
Presione Execute para regenerar con parámetros...
GET /api/horario/exportar Exporta la programación validada a formato CSV (40 líneas: encabezado + 39 sesiones) o JSON auditado (?formato=csv|json). 
Presione Execute para previsualizar el CSV exportado...
